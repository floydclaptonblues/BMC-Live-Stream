# BMC Live Stream

Standalone live-stream landing page for Balcony Music Club.

## Files

- `index.html` — the full standalone BMC live stream page.
- `.nojekyll` — tells GitHub Pages to serve the static page as-is.

## GitHub Pages setup

After pushing this repository to GitHub:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/root`.
5. Save.

The page will publish at:

`https://<github-username>.github.io/<repo-name>/`

To point `balconymusicclub.com/bmc-live` here, configure the domain/hosting layer to route that path to this GitHub Pages site, or embed this page into the current website platform.
